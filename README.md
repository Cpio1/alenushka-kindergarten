# Детский ясли-сад «Алёнушка» — сайт

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion · Lucide.
Основной язык — казахский, переключатель KZ / RU (выбор сохраняется в браузере).
Только светлая тема.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка (перед ней автоматически сканируются медиа)
```

## Как добавить материалы

Все файлы кладутся в `public/`, при `dev`/`build` скрипт `scripts/media-manifest.mjs`
сам считывает размеры и составляет список — код менять не нужно.

| Что | Куда |
| --- | --- |
| Фото главного экрана | `public/main-page.png` (или `.jpg`/`.webp`) |
| Фото «Біз туралы / О нас» | `public/main-page2.png` |
| Видео «Біз туралы» вместо фото | `public/main-page2.mp4` (+ постер `main-page2-poster.jpg`) |
| Логотип (PNG без фона) | `public/logo.png` |
| Галерея | `public/gallery/*` — любые jpg/png/webp, порядок по имени файла |
| Документы | `public/documents/*.pdf` — появятся автоматически с кнопками «Ашу» и «Жүктеп алу» |

Названия и категории документов, ссылки Google Drive — в `src/lib/documents.ts`.

## Карта 2GIS

Точная точка «Алёнушки» в 2GIS не найдена, поэтому на сайте нет случайной метки:
кнопка «2GIS-те ашу» открывает поиск по адресу, «Бағыт құру» строит маршрут по адресу.
Когда точка будет проверена, заполните в `src/lib/site.ts`:

```ts
geo: { lat: 43.xxxxx, lon: 77.xxxxx },
twoGisFirmId: "70000001xxxxxxx", // из ссылки 2gis.kz/.../firm/<ID>
```

— тогда появится встроенная карта и маршрут к точке.

## Vercel

Импортировать репозиторий, настройки по умолчанию. Домен для метаданных — переменная
`NEXT_PUBLIC_SITE_URL` (например `https://alenushka.kz`).
